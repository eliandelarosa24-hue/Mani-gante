# Imágenes de las muestras (Gemini u otras)

Cada muestra usa fotos de Unsplash como respaldo. Para usar **sus propias imágenes** (por ejemplo, generadas con Gemini):

1. Genere la imagen con la descripción sugerida (formato horizontal 16:9 para el inicio y el cierre; 4:5 o 4:3 para el resto).
2. Conviértala a **WebP** (por ejemplo, en squoosh.app), de unos 1600 px de ancho y menos de 300 KB.
3. Guárdela en `public/muestras/<carpeta>/img/<nombre>.webp` con el nombre exacto de la tabla.
4. Ejecute `npm run build` (o vuelva a publicar): la imagen reemplaza sola a la de respaldo, sin tocar código.

**Consejo para Gemini:** agregue siempre "fotografía editorial de viajes, luz natural, sin texto, sin marcas de agua" y el lugar real (por ejemplo, "Araucanía, Chile").
